# Iris Flower Classification

Machine learning project to classify iris flowers into Setosa, Versicolor
and Virginica using their measurements.

## What I did
- Exploratory data analysis (shape, null check, statistics)
- Visualisations: pairplot and box plots
- Trained 4 models: Logistic Regression, KNN, Decision Tree, Random Forest
- Evaluated with accuracy, confusion matrix, classification report
  and 5-fold cross-validation

## Result
Best model: K-Nearest Neighbours (100% test accuracy, 97.3% CV accuracy)

## Tech stack
Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook
